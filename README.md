# Local Voice Agent — speech to clipboard

Локальный голосовой инструмент для Windows: START → запись с микрофона или системного звука → STOP → распознанный текст в буфер обмена. Вставку выполняет пользователь.

Python, faster-whisper, Tkinter, sounddevice/soundcard. Есть выбор устройства, фильтрация пустого распознавания, обработка русских команд и CPU fallback при ошибках CUDA.

## Установка

Python 3.12 с Tkinter, Windows:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start-voice-ia-hidden.bat
```

**Модели не входят в репозиторий.** Перед запуском самостоятельно установите совместимую модель faster-whisper в `models/faster-whisper-large-v3-turbo` или измените `model` в `config.yaml` на путь к своей модели. Если указать поддерживаемое имя модели, faster-whisper может скачать её при первом запуске; это отдельная загрузка, не содержимое Git.

По умолчанию выбран CUDA/float16. Для CPU установите `device: cpu` и `compute_type: int8`. Нужен доступ к микрофону; системный звук зависит от драйверов Windows.

- `start-voice-ia.bat` — запуск с консолью для диагностики.
- `stop-voice-ia.bat` — остановка.
- `python -m src.main --list-devices` — устройства.
- `install-autostart.bat` — необязательное включение автозапуска; обычный старт его не включает.

## Проверка

```sh
python -m pip install pytest
python -m pytest tests -q
```

Тесты обработки команд не требуют модели или записи звука. Аудиоустройства и реальное распознавание проверяются отдельно на компьютере пользователя.

## Локальные данные

`outbox/` содержит журналы, настройки и распознанный текст; `models/` — веса моделей. Эти каталоги, записи голоса, окружение и профили говорящего исключены из Git. Не публикуйте их: в распознанной речи могут быть личные данные. В репозитории нет облачных ключей и записей автора.
